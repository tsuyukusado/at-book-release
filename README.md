# ＠本（at-book）

＠本（アットぼん）は、**日本語小説のための執筆記法と組版ツール**です。

＠マークだけのシンプルな記法で原稿（`.atb` ファイル）を書き、コマンドを一つ実行するだけで、次のものが生成されます。

- 縦書きの**印刷用 PDF**（ルビ・圏点・目次・縦中横・ノンブル付き）
- **EPUB**（電子書籍）
- **小説投稿サイト向けのテキスト**
- ページ数に応じた**表紙テンプレート**（背幅・塗り足しガイド入り）

同人誌や自費出版に必要なものが、これ一つでまかなえます。動作に必要なのは **Node.js だけ**です。

## ＠本の記法

＠本の記法はシンプルです。

| 書き方 | 結果 |
|---|---|
| `＠大見出し` | 大見出しになります |
| `＠＠小見出し` | 小見出しになります |
| `＠目次` | 目次が自動生成されます |
| `＠＠＠` | 改ページされます |
| `＠漢字（ルビ）` | ルビが振られます |
| `＠文字（・）` | 圏点が打たれます |
| `・・` | 三点リーダーに変換されます |
| `＠ー` | ダッシュに変換されます |

以上が全てです。これらの記法は全て、**JISキーボードの日本語入力モードで完結**します。

# クイックスタート

とにかくまずは使ってみたい方へ。前提として **Node.js v18 以上** が必要です（詳しくは [インストールの詳細](#インストールの詳細) へ）。

**1. 作品用のフォルダを用意する**

＠本は、あなたの作品フォルダに**道具として入れて**使います。作品ごとにフォルダを作ってください。

```sh
mkdir my-novel
cd my-novel
npm init -y
```

**2. ＠本をインストールする**

```sh
npm install --save-dev github:tsuyukusado/at-book-release
```

**3. 原稿と設定ファイルを置く**

原稿を入れるフォルダ（ここでは `doc`）を作り、**同じフォルダで** `at-book init` を実行すると、初期値の `at-book.config.json` が生成されます。

```sh
mkdir doc
cd doc
npx at-book init
cd ..
```

`doc/at-book.config.json`

```json
{
  "paperSize": "a6",
  "writingMode": "vertical",
  "autoGenerate": ["your-novel.atb"]
}
```

すでに `at-book.config.json` がある場所で実行すると、上書きせずにエラーになります。

`doc/your-novel.atb` に小説を書きます。使う記法は「＠マーク」だけ。

> `autoGenerate` は**組版する原稿を指定する必須の項目**です。ここに書かないと何も生成されません。

**4. 組版する**

```sh
npx at-book
```

原稿と同じフォルダの `dist/` に、**印刷用 PDF が生成**されます。

> 初回の PDF 生成時のみ、組版に使うプログラム（数百 MB）が自動ダウンロードされます。ネットワークに接続した状態で最初の生成を行ってください。

# インストールの詳細

## Node.js のインストール

＠本の動作には **Node.js v18 以上** が必要です。

### macOS

```sh
brew install node
```

Homebrew が入っていない場合は、[Node.js 公式サイト](https://nodejs.org/ja) から LTS 版をダウンロードしてインストールしてください。

### Windows

[Node.js 公式サイト](https://nodejs.org/ja) から LTS 版のインストーラーをダウンロードして実行してください。

インストール中のオプションはすべてデフォルトのままで構いません。

### Linux (Ubuntu/Debian)

```sh
sudo apt install nodejs npm
```

インストール後、以下のコマンドでバージョンを確認してください。`v18` 以上であれば問題ありません。

```sh
node -v
```

## ＠本のインストール

＠本は、[クイックスタート](#クイックスタート)の手順 2 のとおり**作品フォルダごとに**インストールします。ツール本体を別途ダウンロードしてきて、その中に原稿を書くような使い方はしません。

バージョンを固定したい場合は、タグやコミットを `#` の後ろに指定できます。

```sh
npm install --save-dev github:tsuyukusado/at-book-release#v1.0.0
```

作品ごとに入れる形にしているのには理由があります。

- 作品のデータとツールのデータが混ざらない
- 作品ごとに＠本のバージョンが固定されるので、**去年書いた本を組み直しても組版結果が変わらない**
- パソコン全体には何も入れないので、他の作品や環境に影響しない

インストールできたか確認するには、次のコマンドを実行します。

```sh
npx at-book --version
```

# 使い方

組版までの流れは[クイックスタート](#クイックスタート)のとおりです。ここでは設定ファイルの書き方と、生成される各フォーマットを詳しく説明します。

## 設定ファイル

`at-book.config.json` は、**`.atb` ファイルと同じディレクトリに置いてください**。＠本は原稿と同じ場所にある設定ファイルを読みます。作品フォルダのルートに置いても、用紙サイズなどの設定は反映されません。

作品が複数あるなら、原稿フォルダごとに 1 つずつ置きます。

```
my-novel/
└── doc/
    ├── at-book.config.json   ← ここ
    ├── your-novel.atb
    └── dist/                 ← 生成物はここに出る
```

作品が 2 つあるなら、こうなります。設定ファイルごとに独立しているので、原稿のファイル名が同じでもぶつかりません。

```
my-novel/
└── novel/
    ├── 001/manuscript/
    │   ├── at-book.config.json
    │   ├── manuscript.atb
    │   └── dist/             ← 001 の生成物
    └── 002/manuscript/
        ├── at-book.config.json
        ├── manuscript.atb
        └── dist/             ← 002 の生成物
```

指定できる項目は次のとおりです。

| プロパティ | 値 | デフォルト |
|---|---|---|
| `autoGenerate` | 組版する `.atb` ファイル名の配列 | なし（**未指定だと何も生成されません**） |
| `paperSize` | `a4` / `a5` / `a6` / `b5` | `a6` |
| `writingMode` | `vertical`（縦書き）/ `horizontal`（横書き）| `vertical` |
| `formats` | `pdf` / `epub` / `web` の配列 | `["pdf"]` |
| `bodyPaperThicknessMm` | 本文用紙の厚さ（mm）例: `0.09` | なし |
| `coverPaperThicknessMm` | 表紙用紙の厚さ（mm）例: `0.35` | なし |

### autoGenerate

組版の対象にする原稿を、**設定ファイルから見た相対パス**で指定します。プロットやメモを `.atb` で書いていても、ここに書かなければ組版されません。

## 生成されたファイルの場所

生成物は**原稿と同じフォルダの `dist/` 以下**に保存されます。ファイル名は原稿のファイル名から作られます（`your-novel.atb` なら `your-novel-honbun.pdf`）。

出力先が原稿の位置で決まるので、**どのフォルダから実行しても同じ場所に出ます**。別々のフォルダにある同名の原稿どうしがぶつかることもありません。

| ファイル | 内容 |
|---|---|
| `<原稿のフォルダ>/dist/<名前>-honbun.pdf` | 本文PDF |
| `<原稿のフォルダ>/dist/<名前>.epub` | EPUB |
| `<原稿のフォルダ>/dist/<名前>-hyoshi.svg` | 表紙テンプレート |
| `<原稿のフォルダ>/dist/web/<作品フォルダ>/` | ウェブ投稿用テキスト |

生成結果が気になる時は、随時確認しましょう。

## EPUB（電子書籍）を生成する

紙のPDFだけでなく、**EPUB（電子書籍）** も生成できます。設定ファイルに `formats` を追加してください。

```json
{
  "paperSize": "a6",
  "writingMode": "vertical",
  "autoGenerate": ["your-novel.atb"],
  "formats": ["pdf", "epub"]
}
```

- `["pdf", "epub"]` … PDFとEPUBの両方を生成します。
- `["epub"]` … EPUBのみを生成します。
- `["pdf", "web"]` … PDFに加えて、ウェブ投稿用テキストも生成します（[ウェブ投稿用のテキストに変換する](#ウェブ投稿用のテキストに変換する) を参照）。
- 未指定（項目なし）… 従来どおりPDFのみを生成します。

生成されたEPUBは `<原稿のフォルダ>/dist/<ファイル名>.epub` に保存されます。ルビ・圏点・縦書きはそのまま引き継がれます。

改ページ（`＠＠＠`）・大見出し（`＠`）・目次（`＠目次`）の区切りは、どの電子書籍リーダーでも確実に改ページされるように処理されます。

> **EPUBはリフロー型です。** 読者が端末で文字サイズを変えられる形式のため、ページ番号（ノンブル）・綴じ代・コロフォンといった「紙面固定の装飾」や表紙テンプレートは付きません（これらはPDF専用です）。また本文フォントは埋め込まず、読者の端末のフォントで表示されます。

## 表紙テンプレートを生成する

＠本では、生成したPDFのページ数に応じた**表紙のテンプレート**も生成することが出来ます。

上述した設定ファイルに、以下の項目を追加してください。

```json
{
  "bodyPaperThicknessMm": 0.09,
  "coverPaperThicknessMm": 0.35
}
```

本文用紙・表紙用紙それぞれの厚さを mm で指定します。両方を設定すると、本文PDFと同時に `<原稿のフォルダ>/dist/<名前>-hyoshi.svg`（背幅・塗り足しガイド入り）が生成されます。

## 設定ファイルを初期生成する

```sh
npx at-book init
# → カレントフォルダに at-book.config.json が生成される
```

原稿を入れるフォルダで実行してください。同じフォルダに既に `.atb` があれば、`autoGenerate` に自動で指定されます。無ければプレースホルダーが入るので、書き換えてください。既に `at-book.config.json` がある場所では上書きせずエラーになります。

## 手動でPDF生成を実行する

上述した全ての自動生成機能は、コマンドを使って手動で生成する事も可能です。

### ビルドする対象を指定する

原稿・設定ファイル・フォルダのいずれでも指定できます。どれも「設定ファイルを起点に作品を特定する」同じ操作です。

```sh
npx at-book                                     # カレントフォルダ配下を全部
npx at-book novel/001                           # そのフォルダ配下を全部
npx at-book novel/001/manuscript/at-book.config.json   # その設定ファイルの分だけ
npx at-book doc/sample.atb                      # その原稿だけ
# → doc/dist/sample-honbun.pdf が生成される
```

フォルダを指定した場合は、その配下にある `at-book.config.json` を再帰的に探して、`autoGenerate` に書かれた原稿をまとめて組みます。作品が増えても「この作品だけ組み直す」ができます。

### 表紙テンプレートをページ数指定で単体生成する場合

```sh
npx at-book cover 160 0.09 0.35
# → dist/cover-template.svg が生成される
```

引数は順に「ページ数」「本文用紙の厚さ（mm）」「表紙用紙の厚さ（mm）」です。

## ウェブ投稿用のテキストに変換する

＠本の記法で書いた原稿を、小説投稿サイト向けのテキストに変換できます。

```sh
npx at-book web doc/sample.atb
# → doc/dist/web/<作品フォルダ>/ 以下にテキストが生成される
```

設定ファイルの `formats` に `web` を加えれば、PDF などと同時に自動生成することもできます（[EPUB（電子書籍）を生成する](#epub電子書籍を生成する) を参照）。

記法は次のように変換されます。

| ＠本の記法 | 変換後 |
|---|---|
| ルビ `＠漢字（かんじ）` | `｜漢字《かんじ》` |
| 圏点 `＠文字（・）` | `｜文《﹅》｜字《﹅》`（一文字ずつ） |
| ダッシュ `＠ー` | `――`（レベル分くり返し、直接記述） |
| 三点リーダー `・・` | `…`（中黒の数だけ、直接記述） |

分割とフォルダ構成は次のとおりです。

- **見出しで分割**されます。`＠見出し`（章）が**フォルダ**、`＠＠小見出し`（話）がその中の**テキストファイル**になります。
- **最初の見出しより前の文章**が作品タイトルとなり、その**冒頭5文字**が作品フォルダ名になります。
- 章（`＠見出し`）の直下、最初の小見出しより前に書かれた本文は、章見出し名のファイルとして出力されます。
- **小見出し（`＠＠`）が作品全体に1つも無い場合**は、章フォルダを作らず、各`＠見出し`のファイルを作品フォルダの直下にまとめて出力します。
- 章フォルダ・話ファイル名の先頭には**連番**が付きます（`01_タイトル`）。章番号は作品を通して、話番号は**章ごとに `01` からリセット**して振られます（例: `01_第一章　旅立ち/02_朝の支度.txt`）。ゼロ埋めの桁数は件数に応じて自動調整されます。
- **地の文は行頭に全角スペースが1つ入り**、一字下げされます。開きカッコ（`「『（〈《【〔［｛` や半角 `( [ {`）で始まる行（会話文など）、箇条書き（`・`）、空行、すでに全角スペースで始まる行は下げません。
- `＠目次` は削除、`＠＠＠`（改ページ）は改行、箇条書き（`・`）はそのままのテキストになります。
- 縦中横（`！？` や半角数字）はウェブでは横書き前提のため、そのまま出力されます。

## git で原稿を管理する（任意）

＠本の動作に git は**必要ありません**。ただ、原稿をテキストファイルで書く＠本は git によるバージョン管理と相性がよく、変更履歴の記録や書き直しの巻き戻しができるようになります。

git で管理する場合は、作品フォルダで `git init` した上で、`.gitignore` に次の 2 行を加えてください。生成物はいつでも作り直せるので、リポジトリに入れる必要はありません（`dist/` と書いておけば、どの階層の `dist/` にも効きます）。

```
dist/
node_modules/
```

# 困ったときは

## 何も生成されない・設定が効かない

- `at-book.config.json` に `autoGenerate` を書いているか確認してください。ここに書かれた原稿だけが組版の対象です。
- 設定ファイルが `.atb` と**同じフォルダ**にあるか確認してください。＠本は原稿と同じ場所にある設定ファイルだけを読みます。用紙サイズや縦書きの設定が効かないときも、まずここを疑ってください。

# おすすめの執筆環境：VSCode × ＠本

＠本はどんなテキストエディタでも使えますが、わたしのおすすめは **VSCode** との組み合わせです。

VSCode（Visual Studio Code）は、Microsoftが無償で提供する高機能テキストエディタです。もともとはプログラマー向けに作られたものですが、その強力なカスタマイズ性から、今では小説執筆にも活用されています。

- **無料**で使える
- Windows・macOS・Linuxすべてで動作する
- 専用拡張機能によって、＠本の各種記法に色がつき、とても見やすく書ける
- gitによるバージョン管理と組み合わせれば、原稿の変更履歴を自動で記録でき、加筆修正が思うように行かなかった時もいつでも巻き戻せる
- GitHubにPushすれば、スマホからも執筆できる

VSCodeで書く → ＠本を走らせる → そのまま出版・投稿できるデータが**生成**される。

このツールを使えば、**あなたが書いた小説はその場で本になる**のです。あなたがすることは、もはや**書くことだけ**。それが、**VSCode × ＠本**です。

## VS Code 拡張のインストール

`.atb` ファイルの構文強調表示を有効にします。VSCodeで執筆する場合はぜひ入れておいてください。

拡張は VS Code Marketplace には未公開のため、リポジトリから `.vsix` ファイルを入手します。

1. [at-book-release リポジトリ](https://github.com/tsuyukusado/at-book-release) の `vscode-atb/vscode-atb-0.1.4.vsix` をダウンロード
2. VS Code の左サイドバーで拡張機能アイコンをクリック（または `Ctrl+Shift+X` / `Cmd+Shift+X`）
3. 右上の `…` メニューから「VSIX からインストール...」を選択
4. ダウンロードした `vscode-atb-0.1.4.vsix` を選択してインストール
5. VS Code を再起動

# ＠本自体を開発する方へ

組版エンジンは HTML/CSS ベースの [Vivliostyle](https://vivliostyle.org/) です。原稿を HTML に変換し、Vivliostyle CLI（同梱のヘッドレスブラウザ）で PDF / EPUB に組みます。LaTeX（TeX Live）には依存していません。

＠本そのものに手を入れる場合は、リポジトリをクローンして次を実行してください。

```sh
git clone https://github.com/tsuyukusado/at-book-release.git
cd at-book-release
npm install
npm run setup
```

`npm install` はビルドまでしか行いません。`npm run setup` はそれに加えて `npm link` を実行し、`at-book` コマンドをグローバルに通します。

```sh
npm test               # テストを実行
npm run test:coverage  # テストカバレッジを計測
npm run build          # TypeScript をビルド
npm pack               # 配布用の tarball を作る
```

テスト項目の一覧は `doc/test-items.md` にあります。
